# Security dependency pins — the single source of truth for both scopes they apply to.
#
# These overrides have to be installed twice: once on the Gradle plugin classpath
# (`buildscript {}` in the root build file) and once on every project configuration. Kotlin DSL
# evaluates the buildscript block before any top-level declaration in the same file, so the two
# scopes cannot share a Kotlin constant — and when the rules were written out longhand in both
# places they drifted: commons-io was pinned to 2.18.0 in one and 2.20.0 in the other, and the
# project-scope rule for it named a group (org.apache.commons) that commons-io has not published
# under since 1.3.2, so it matched nothing. Keeping the table here as data means a pin is written
# once and both scopes read the same line.
#
# Format, one pin per line:
#
#     group:nameGlob | version | reason
#
# `*` in the name matches any run of characters; everything else matches literally. The reason is
# passed to Gradle's `because()`, so it shows up in dependency-insight output. Blank lines and
# anything after a `#` are ignored.
#
# The version is a floor, not an exact force: a dependency that already resolves higher is left
# alone. Forcing exactly is a downgrade dressed as a security fix, which is what the httpclient
# entry below was doing — pulling the tree's 4.5.14 back to 4.5.13 every build.
#
# Use a glob only where the matched artifacts genuinely share one version line — Bouncy Castle's
# jdk18on artifacts do, OpenTelemetry's do not (its -alpha modules version separately), which is
# why the two OpenTelemetry artifacts are listed out.

# Was pinned to a nonexistent "4.1.139.Final", which never failed only because nothing resolved a
# Netty artifact through these configurations; the first dependency that did (UTP, via the
# benchmark module) broke the build outright.
#
# 4.1.137.Final is the 4.1-line fix for CVE-2026-59903: CorsHandler's setVaryHeader overwrote a
# Vary header the application had already set, so a cache in front of it could serve one user's
# response to another. 4.1.136.Final — what this pinned before — is the last affected release.

org.apache.commons:commons-compress                 | 1.28.0        | Dependabot reports Apache Commons Compress CVEs.
