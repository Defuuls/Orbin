## Current Coral behavior

- Boards, Home/Feed, Downloads and Settings are the four primary destinations. The shared bottom bar uses the real active-download count. Settings/Downloads replace each other without losing the reader beneath them; existing drawer destinations and hierarchical Back remain available. Native Home/Boards heading identifiers and the single Orbin wordmark announcement are retained.
- Home and catalogs use responsive Coral Grid cards by default when no preference is stored. A saved List choice survives. Home retains static previews, explicit media versus thread actions, per-source anchors, long-press options and eligible explicit subscriptions; no For You/Following selector or inline media pager is introduced.
- Search uses pill entry, real query/retry and source filtering that survives loading. Saved, Watched and History use source-qualified stored-record cards. Downloads uses keyed lazy cards, actual status/progress, separate retry and confirmation before clearing history.
- Settings categories and sub-pages use Coral cards and search while retaining IDs, values, validation, switches and anchored choices. Existing backup refusal and legacy-key migration remain independent from appearance. Bundled Roboto and the single system-text scaling path remain in place.
- The media wall uses Coral attachment cards. Media entry carries the source/thread/attachment identity and thumbnail hint: exact identity wins, a unique matching thumbnail can recover a catalog preview, and missing/ambiguous selections show an unavailable state. Loading/failure entry retains Close and real Retry.
- The viewer provides visible Close and persistent Download, double-tap save, guarded horizontal swipe to close, image pinch/pan and vertical paging. Playback offers 1x, 1.25x and 2x while retaining the selected attachment and pause state, including WebM. Download rest of thread queues the other attachments from that thread through the existing deduplicated queue.
- Long Posts threads expose a shared fast-scroll thumb with accessible progress and one conflated scroll worker. Short threads and Files do not gain a dead scrollbar. Two-pane widths/visibility/retained-state rules are preserved inside the Coral frame and empty-detail card.
- Mandatory setup, app lock, safe mode, release notes, update/local-data dialogs, sheets and snackbars share Coral chrome. First-run completion still requires a persisted eligible follow and an explicit Start action. Provider selection, disabled saving state, Back/focus and native labels remain contracts.
- Saved HTML archives use the canonical light/dark palette and native, initially closed spoiler disclosures. Nested colored text and links remain hidden until activation; keyboard and pointer interaction require no script. Escaping and file/quote links are preserved.

Orbin remains **read-only**: no post, reply or composer control is added. Existing board icons, the card-stack app identity, explicit subscriptions, source-qualified records and dedicated playback remain functional Orbin features.
