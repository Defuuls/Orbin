# Reader implementation and verification

This record tracks the implementation of the [normative reader design](README.md). The implementation guide is a delivery brief; its historical review and approval conversations are not application requirements. The design README remains authoritative for behavior and tokens.

**Status: Home reader correction is implemented and local strict validation has passed.** Version 199 shipped the reader catalog, thread and navigation frame but retained the old Home media pager. Its passing checks did not establish the new Home content layout. This record distinguishes source coverage, executed checks, screenshot comparisons, generated profiles and physical-device observations. A passing checkpoint applies only to the source it tested.

## Reference-led refinements

Clover, KurobaEx and Chance inform the selected patterns recorded in the [source record](README.md#design-influences). Orbin retains its own identity, feature set and source data. Reference code and assets are not shipped.

- Saved now uses real stored thread records in a compact reader list, with source, saved time, thread number and actual unread metadata. `ThreadCollectionInteractionTest` and `ReaderSavedScreenshotTest` cover its behavior and twelve theme/window captures.
- The existing source-grouped board picker and Boards search are retained. A further search field inside the picker is deferred; it is outside the required style correction. `ReaderCatalogControlsTest` continues checking qualified selection and accessibility.
- Home adds an optional explicit Reload action beside Search. Search copy describes the existing followed-board, cross-site catalog scope accurately.
- The iOS media viewer keys attachments by identity and source URL so insertion, reordering and removal preserve the selected file where possible. `MediaViewerIdentityTest` renders the actual viewer with the Android host player stub; native `PlayerHostTest` remains the decoder evidence.

These refinements are implemented. Final-source local tests, coverage, lint, Android test-APK compilation, iOS compilation and strict screenshot comparisons passed. Current-revision CI, installed-device checks and distribution receipts are recorded in the corrective pull request and its workflows. Quantitative catalog/thread benchmark results must not be presented as populated-Home performance measurements.

## Home correction readiness

Home now follows the [Home rules](README.md#home): canonical List/Grid cells and theme colors, feed/source controls below the app bar, bounded static thumbnails and explicit media opening. The old full-screen pager, over-media action rail and Home inline autoplay contract are retired. The existing media viewer remains the explicit playback destination. The shared app theme selects the platform-default sans serif for its controls; retained bundled font assets are not evidence that the app theme selects the previous typeface.

The new Home uses the public [FeedScreen](../../ui-next/src/commonMain/kotlin/com/orbin/uinext/FeedScreen.kt) entry point and shared [catalog cells](../../ui-next/src/commonMain/kotlin/com/orbin/uinext/BoardCatalog.kt). Android and iOS must both pass the remembered catalog mode and explicit media-opening callback. Each source and feed tab retains its own reading position. Watch, Save, Share, board and thread videos/comments actions remain available through the row menu.
