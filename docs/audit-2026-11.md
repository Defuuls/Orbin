# Orbin code and design audit — November 2026

Baseline: `ae691cbe12de99692ab1f382501126c5da1f235d` (190-Puntarelle).

## Scope and evidence

This is a broad static audit of Android and iOS settings, shared Compose screens,
navigation and startup boundaries, settings persistence and backups, saved threads,
provider transports, downloads, and build/release automation. Existing settings,
feed, thread and media screenshot baselines were inspected. No repository-specific
agent instructions were present.

The selected cloud executor could not execute commands. Source was read through
the GitHub connector. Existing screenshots are fixture baselines, not renders of
these changes. This report does not establish device behavior, performance, or an
exhaustive security assessment.

## App-wide redesign (OPTIC-26)

The shared native UI has been upgraded to the **OPTIC-26** industrial design
system across Feed, Boards, threads, media, downloads, onboarding and settings:
anodized obsidian (`#0A0A0C`), true-zero carbon (`#000000`) and raw titanium
(`#F4F2ED`) grounds paired with International Orange (`#9E3608` / `#FF7A3D`)
optical accents, 40 sp heavy titles with a 6-blade optical aperture emblem,
machined uniform `2 dp`/`4 dp`/`6 dp`/`8 dp` radii, structural `1 dp` borders,
tabular numerals (`tnum`), and critically damped zero-bounce spring physics.
Existing theme choices and body text scaling remain available. A large-text
dock regression covers readable labels and target sizes. Screenshot review
covers representative normal, maximum-text, dark and AMOLED states.

## Findings addressed in this change

| Area | Problem | Change and regression coverage |
| --- | --- | --- |
| Settings design | Two unnamed groups make appearance, privacy and data actions hard to scan; settings have no search. | Named task sections on both platforms; shared search matches section, label, hint, current value and options. Secret values and text drafts are excluded. Values wrap below labels to remain readable at large text sizes. Search and registry tests cover filtering and row preservation. |
| Settings accessibility | The row and switch expose duplicate actions; the row does not expose checked state. | One labeled action with checked semantics; passive visual switch. Shared interaction test covers one callback and state changes after searching. |
| iOS controls | A 51 × 31 dp switch track has no checked semantic state and insufficient touch height. | An outer 48 dp minimum toggle target retains machined `OPTIC-26` track dimensions. Platform tests cover both platforms and passive switches. |
| Shared accessibility | Pull-to-refresh requires gestures; snackbars always time out after four seconds without an announcement. | Add a semantic refresh action, polite announcements and accessibility-recommended timeout. Tests exercise current busy state and actual dismissal timing. |
| Onboarding | Follow rows and their switches duplicate the same action. | One row toggle; interaction test verifies one action and state. |
| Backup feedback | Android reports saved searches rejected during import as restored. | Count accepted searches; test mixed valid/invalid entries in both restore modes. |
| Project link | iOS promises feedback through a disabled GitHub issues page. | Open the existing project repository and label the destination truthfully. |
| iOS restore | Older backups can restore incomplete setup and reopen onboarding during import. | Complete setup after restore while preserving app-lock policy; regression covers older documents. |
| Deletion feedback | Android shows success before clearing finishes or fails. | Report completion only after all operations finish; show failure instead of false success. Tests cover a suspended cache and a failed deletion. |
| iOS deletion | Two-tap destructive confirmation never expires and understates what is deleted. | Match Android's four-second expiry and name history, download records and image cache. |
| Saved media | Saved audio, blank-filename slots, and extensionless original filenames lose positional pairing or reload as images. | Preserve positional slot pairing when `originalFileName` is blank and fall back to URL extension when `originalFileName` lacks an extension; roundtrip tests cover playable state and positional pairing. |
| Provider transport & entities | Nonstreaming requests buffer responses before the 16 MiB limit; LynxChan board/thread/poster strings leave HTML entities undecoded. | Stream successful JSON within the limit, classify HTTP errors without reading bodies, and decode HTML entities across LynxChan board/subject/poster fields. |
| Network headers | `HeadersInterceptor` was registered twice on `BaseOkHttp` and overwrote explicit `Accept` headers on extensionless video URLs. | Register `HeadersInterceptor` once and preserve any existing `Accept` header on requests; unit test covers extensionless video URLs. |
| Feed autoplay & audio focus | Thumbnail-only catalog video stubs attempted autoplay, and muted players requested exclusive audio focus on Android and iOS. | Require a distinct non-blank `sourceUrl != thumbnailUrl` for feed autoplay, tie `handleAudioFocus` / `AVAudioSessionCategoryAmbient` to mute state, and seek to `0` on replay after ended state. |
| Startup crash recovery & DI | `OrbinApplication` eagerly initialized `SharedGraph` (SQLCipher/Room/DataStore) before installing crash-loop detection, `resetLocalData()` missed `files/datastore`, and `SharedGraph` instantiated two `SettingsRepositoryImpl` instances over one DataStore. | Defer `ProviderDiagnostics` and `OrbinApplication` dependencies with `Provider`/`Lazy`, delete `files/datastore` in `resetLocalData()`, and bind a single `@AppScope` `SettingsRepositoryImpl`. |
| Board observation | `BoardRepositoryImpl.observeBoards` blocked cached Room emission on stale network refresh inside `onStart`. | Emit cached Room rows immediately via `channelFlow` while deduplicating background refresh with a `Mutex`. |
| Platform parity & theme nesting | Nested `NextTheme` dropped custom palettes, `PostCommentText` used light-only quote/greentext colors on dark surfaces, `DownloadRow` double-wrapped cards inside `GroupedSection`, and iOS threads only rendered the first attachment of multi-file posts. | Inherit custom palettes across nested `NextTheme`, adapt quote/greentext colors to surface luminance, flatten `DownloadRow` inside `GroupedSection`, and add `HorizontalPager` multi-attachment rendering on iOS. |
| Release source | Build and publish resolve a mutable branch separately; existing tags are accepted without checking the source. | Pass the build's immutable SHA to publish; reject mismatched or changed tags before release publication. No release workflow was run. |
| Build reliability | Parallel KSP 2.3.13 tasks intermittently lose generated Hilt modules or classpath symbols. Same-source CI siblings pass or fail before application tests. | Serialize KSP tasks through a shared Gradle service and invalidate earlier KSP outputs, retaining parallel compilation/tests. Matches [upstream issue 3286](https://github.com/google/ksp/issues/3286). |
| Quality gates | Python regression suites and rendering dependency changes can miss their relevant checks; temporary PR #791 base64 log export remained in `screenshots.yml`. | Run Python tests in CI and the local check script, remove temporary log-export job from `screenshots.yml`, and retain golden verification. |
