Native decoding uses FFmpeg VP8/VP9 and Opus support. Encoding uses Apple's
VideoToolbox H.264 encoder and FFmpeg's AAC encoder. No libx264, libx265, or
nonfree codec is enabled. The archive's generated config.h declares
FFMPEG_LICENSE "LGPL version 3 or later" and the native adapter verifies
GPL/nonfree build flags before use.

Supporting library source/licenses can be obtained from the pinned builder's
source and build scripts. Rebuild the same dynamic framework and relink using
Orbin's published XcodeGen and local SwiftPM package sources.
